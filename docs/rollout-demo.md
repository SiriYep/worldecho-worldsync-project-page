# Recorded rollout comparisons

The local preview at `#state-control` now contains seven cases, each with one
simulator GT and thirteen model configurations. A selector switches the twelve
baseline configurations while retaining GT and WorldSync. Recordings are not
generated by the action-draft playground.

## Selection and identity

Source pack: `main50_13models_10per_task_20260915`.
The full index has 6,500 rows: 500 common samples, 50 tasks, 13 configurations.
Index SHA-256: `c1a46ba5e9111cb1b14ac436c09dfd771661a3fda9a8710361a26da6805ec313`.

Seven task/category pairs were chosen to cover the five query types and all
seven subtypes. Each uses the first sample in pack order for that pair. Scores
were not used to select cases. This is a qualitative subset, not a representative
performance estimate.

| Task | Query subtype |
| --- | --- |
| Adjust bottle | Expert / clean |
| Grab roller | Local perturbation / PCA |
| Handover block | Local perturbation / raw |
| Place bread in basket | Cross-state replay |
| Rotate QR code | Policy rollout |
| Stack two blocks | Feasible-space sampling / uniform |
| Lift pot | Feasible-space sampling / weighted |

`assets/rollout-demo/catalog.json` binds every clip to its original chunk ID,
model configuration, training regime, step, action hash, and shared input.
The source pack identifies WorldSync as `WanWorld-mix4-ie-afe-no-robot`, step
60000 (`fresh_wanworld_norobot_50task_core5_20260722`). Baselines use Expert at
20k or Expanded at 40k. These training budgets differ. LingBotVA is video-only:
its comparison uses the same query's recording but the model does not consume
the action array.

## Media and playback

- 98 videos: seven GT and 91 model outputs. All decode completely.
- 77 H.264 videos are byte-identical copies. The other 21 were MPEG-4 Part 2;
  browser copies use H.264 CRF18, preserving frame count, frame rate, dimensions
  and duration. This re-encoding is lossy; original files remain in the audit
  archive. Posters come from frame zero of the displayed video.
- GT and Cosmos-Predict2.5 use 33 frames at 22 fps. LingBotVA uses 32 frames at
  10 fps. Other models use 33 frames at 30 fps. Source sizes range from 224×168
  to 640×480. Videos retain their full image in an `object-fit: contain` frame.
- The common slider follows normalized clip progress, not physical timestamps.
  Playback changes rates to cover each complete recording. No frame-level
  physical time correspondence is implied.
- The input PNG is the source pack's model input observation, and `action.npy`
  is the original `(32,20)` float32 Rot6D20 delta-EE array. Downloads do not
  execute robot motion.
- Playback pauses out of view or when the page is hidden. Reduced motion starts
  paused. Changing sample or model preserves a deliberate pause.

## Score boundary

The demo does not display sample-pack metrics. The pack distinguishes report
lineage gated/pass values from later paper rescoring. CtrlWorld and
Cosmos-Predict2.5 also contain older AnyPos trajectory arrays alongside newer
reported scores. Those arrays must not be silently combined with the other
configurations or presented as the current paper's scorer output.

The existing leaderboard is unchanged. This media audit validates the supplied
pack and selected browser assets; it is not a new inference run, a full 50-task
score reproduction, or an independent checkpoint tensor audit.

## Local preview

```sh
npm run build
python3 scripts/preview.py --port 4190
```

Open `http://localhost:4190/#state-control`. The preview server supports byte
ranges required for video seeking. A plain `python -m http.server` can fully
load a video while still leaving its seekable range empty in Chromium.

Site tests: `npm test`. The media-generation script, original assets, complete
SHA receipts, source index and AFE/metric review are retained in the separate
internal `20260915-demo-appendix` audit directory. The build copies only public
demo media/catalog, not the internal report or source-run metadata.
